Adonis Sentinel provides the building blocks you need to manage authentication in an AdonisJS application. It does not replace `@adonisjs/auth`: it sits next to it and takes care of the flows around it.

<Callout type="warn">
  Sentinel is under active development and has not been released yet. The API described here is
  subject to change.
</Callout>

## Building blocks

- **Email management:** Verify email addresses and handle email changes
- **Password management:** Reset forgotten passwords and update existing ones
- **Magic links:** Sign users in with a single-use link sent by email
