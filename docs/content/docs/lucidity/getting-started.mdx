Lucidity is a plain library: there is no provider to register and no configuration file to generate. Install the package, then import the features you need into your models.

<div className="fd-steps [&_h2]:fd-step">

## Installation

Install the package using your package manager:

```package-install
npm install @foadonis/lucidity
```

Peer dependencies: `@adonisjs/core ^7.0.0`, `@adonisjs/lucid ^22.0.0`, `luxon ^3.5.0`.

## Pick a feature

Each feature is independent and opt-in. Use one, two or all of them in the same model.
